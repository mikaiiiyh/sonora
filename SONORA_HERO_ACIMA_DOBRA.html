DADOS · FONTES · MÉTODO

Como a SONORA transforma dados musicais em análise estatística.

A SONORA não cria os dados musicais. Primeiro ela consulta fontes públicas de catálogo e ranking; depois organiza essas informações e aplica os cálculos estatísticos sobre o conjunto encontrado.

01 · Catálogo musical

Para cada pesquisa, a SONORA consulta a iTunes Search API. Os resultados podem trazer o nome da faixa, artista, álbum, gênero principal, data de lançamento, duração, capa e links de visualização. Quando a pesquisa é exatamente um artista, o site usa o artistId retornado pela Apple para buscar as faixas e álbuns ligados àquele artista, evitando misturar homônimos.

Documentação da iTunes Search API →

02 · Popularidade que não é inventada

O número mostrado como popularidade não é uma pontuação criada pela SONORA. O perfil tenta primeiro o Top 100: Global da Apple Music. Se essa fonte não puder ser consultada pela conexão/navegador, o sistema tenta o Billboard Global 200, que combina streaming e vendas de mais de 200 territórios. A posição exibida é sempre a posição real encontrada na fonte, nunca uma nota inventada.

Apple Music · Top 100 Global → Billboard · Global 200 →

03 · O que os gráficos calculam

Correlação mede a direção e a intensidade da relação linear entre duas variáveis. Covariância indica se elas tendem a variar juntas ou em sentidos opostos. Regressão linear ajusta uma reta para resumir a tendência dos pontos. Esses três valores não vêm prontos da Apple: são calculados pela SONORA a partir dos dados coletados.

04 · Por que uma fonte pode não ter um dado?

Catálogo e ranking têm funções diferentes. O catálogo descreve a obra; o ranking mostra uma posição naquele recorte específico. Por isso, uma música pode ter ano, gênero e álbum perfeitamente conhecidos e, ao mesmo tempo, estar fora do Top 100. Nesse caso, a SONORA não preenche o espaço com um número estimado: informa exatamente o que a fonte permite afirmar.

05 · Fontes para consulta

As fontes ficam abertas para que qualquer pessoa possa conferir o método e entender de onde os dados vieram. Para popularidade, a SONORA prioriza o ranking global da Apple Music e usa o Billboard Global 200 como fallback quando a primeira fonte não está acessível.
