## 🎵 Sobre a SONORA

A **SONORA** é uma plataforma de análise musical que transforma dados sobre músicas e artistas em uma experiência visual, interativa e fácil de explorar.

O projeto nasceu como uma atividade acadêmica desenvolvida por três estudantes e evoluiu para uma experiência real que conecta **música, estatística, visualização de dados e tecnologia**.

---

## ✨ O que a SONORA faz

- 🔎 Pesquisa artistas e músicas
- 🎧 Apresenta informações musicais
- 📊 Explora dados e estatísticas
- 🧬 Cria o Perfil Sonoro
- 🔄 Permite explorar relações entre dados musicais
- 📈 Apresenta visualizações interativas
- 🎵 Conecta características musicais a análises estatísticas
- 📤 Permite compartilhar análises e o Perfil Sonoro

---

## 🎧 Perfil Sonoro

O **Perfil Sonoro** transforma características musicais em uma experiência visual personalizada.

A proposta é permitir que cada pessoa descubra uma leitura própria dos dados musicais e compartilhe o resultado com outras pessoas.

> **E qual é o seu Perfil Sonoro?**

---

## 📊 Análises

A SONORA explora diferentes formas de analisar dados musicais:

| Análise | O que explora |
|---|---|
| Distribuição Estatística | Comportamento e distribuição dos dados |
| Correlação e Covariância | Relações entre características |
| Regressão Linear | Relações e tendências |
| Clustering | Agrupamentos por semelhança |
| Análise Fatorial | Relações entre variáveis |
| Correspondência | Relações entre categorias |
| Séries Temporais | Comportamento ao longo do tempo |

---

## 🧠 Como funciona

A experiência da SONORA pode ser resumida em:

**Pesquisar → Ouvir → Explorar → Analisar → Compartilhar**

A interface combina elementos musicais, como ondas sonoras, capas e equalizadores, com gráficos e visualizações de dados.

## 🎨 Identidade

A identidade visual da SONORA combina:

- 💜 Roxo / lilás
- 🤍 Cream / off-white
- 🤎 Marrom
- 🩵 Azul pastel
- 🌸 Rosa pastel
- 💛 Amarelo suave

O **S roxo/lilás** é um dos principais elementos da identidade.

A linguagem visual combina música e dados através de ondas, gráficos, círculos, equalizadores, capas e elementos editoriais.
